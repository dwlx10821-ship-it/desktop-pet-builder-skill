# Desktop Pet Request Template

Copy this template into a new request and fill in only what matters:

```text
Create a Windows desktop pet.

Reference image(s): <attach images or provide absolute paths>
Pet name: <name, or let the AI choose>
Visual style: <anime / painterly / pixel / keep the reference style>
Personality: <brief description>
Relationship mode: <ordinary pet / companion / girlfriend / none>
Required actions: <for example idle, wave, sleep, code, fix bug, celebrate>
Cursor behavior: <none / look toward cursor / follow cursor>
Chat: <offline only / OpenAI-compatible API / no chat>
Proactive chat: <yes/no; preferred interval if yes>
Packaging: <EXE / source folder / both>
Other constraints: <colors, contour, speed, props, privacy requirements>
```

The AI should ask for a missing API key only through a local settings field or environment variable. Do not paste secrets into the prompt when a settings screen can be provided.
